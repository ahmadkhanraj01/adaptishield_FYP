# attack_lab

**Status:** not built yet (Phase 3 in [Phase.md](../.agent/project/Phase.md)).

Module 2, the Attack Lab: browse attacks from InjecAgent and AgentDojo (`red_team/data/`) or write a custom one, run it with protection off and on, and compare the results. Batch runs report progress over the WebSocket.

Results on AgentDojo's attack set must not be used to tune rules ([Rules.md](../.agent/project/Rules.md) §6).
