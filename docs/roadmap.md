![Gantt chart](assets/gantt_chart.png)

## What each phase delivers

**Phase 2.** `docker compose up` starts the backend and database. A request returns a verdict and streams each stage live.

**Phase 3.** From the browser, run an InjecAgent attack against the Demo Agent with protection on and off, and see the difference.

**Phase 4.** The full web app works against the real backend.

**Phase 5.** A test report and evaluation results across all three setups, by attack type.

**Phase 6.** A deployable prototype, user manual, developer guide, final report, demo video and final presentation.
