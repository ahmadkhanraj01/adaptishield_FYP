# writeup/ — the paper, section by section, in bullets

**Created:** 15 September 2026, the day the research phase closed.
**Purpose:** a study guide for writing the paper in your own words. Every section
of the paper is one file of plain-language bullets. Each bullet carries the exact
number it rests on, the file under `results/` that number comes from, and a
`[meaning …]` bracket that says the same thing in the simplest possible words.

This folder does **not** replace `paper/manuscript.md`. The manuscript is the
full draft an examiner reads. This folder is what you read *before* writing, so
that you understand each point well enough to say it yourself.

## How to use it

1. Read the file for the section you are about to write, top to bottom.
2. For every bullet, ask: *can I explain this to a classmate without looking?*
   If not, the `[meaning …]` bracket is the version to start from.
3. Write the section in your own words. Keep the numbers exactly as given, with
   their `n` and interval. They are the only part you must not paraphrase.
4. When you need the source, the bracket after each number names the file. Every
   file is under `results/` and regenerates from one committed command
   (`results/README.md` is the index).
5. Write the abstract **last**, from `00-abstract.md`, after the other six
   sections exist in your words.

## One rule that governs all of it

Every number in this folder is written as `value [95% CI] (n, source file)`.
If you find a number without a source, it has not been measured and must not
appear in the paper. This is `Rules.md` §7, and it is the reason the paper can
survive a reviewer.
