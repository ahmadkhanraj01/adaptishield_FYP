# Paper figures

Generated by `python3 paper/make_figures.py`, **never hand-drawn**. Each reads a
committed `results/` file and fails if it is missing, so a figure cannot drift
from the number it depicts. Re-run after any results change.

Palette: Okabe-Ito, validated colorblind-safe for print (dataviz six-checks,
light surface — all pass, worst adjacent CVD ΔE 11.0). Print-only on white; PDF
(vector, for LaTeX `\includegraphics`) + PNG (preview) each.
